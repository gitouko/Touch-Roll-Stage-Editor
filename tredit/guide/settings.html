Settings

Edit > Settings… (Ctrl+,) gathers everything you can set in one window, one page per topic. Changes take effect straight away, and Reset this page puts a page back the way it came. Hover over a setting to see what it does.

General

Pick a dark or light look, or let the editor follow Windows, and make the text bigger or smaller. You can also have the editor open the ROM you used last instead of showing the start page.

Editing

How far things snap when you drag them, how far the arrow keys move the selection, how many degrees Q and E turn (with and without Shift), whether a dragged object keeps its height above the floor, how high new bananas float, and whether new goals turn to face the start.

New platforms and models

The size of the square you get when you click instead of dragging, the thickness of new platforms, and which texture they start with: the stage's main floor, or the last texture you picked in that stage. The starting size of a new stage's platform, and the starting choices of the OBJ import window (up axis, Both sides, the file's texture coordinates) live here as well.

Map

The grid, the collision overlay and which way the side view looks, the same as in the View menu, plus the size of the object markers and the colours of the collision overlay.

3D view

Field of view, how fast the mouse turns the view and whether up and down are swapped, crisp or smooth textures, the background colour, and smooth edges. Smooth edges are set up when the 3D view is created, so that one takes effect the next time you start the editor.

Saving and testing

Where BizHawk is, the name suggested for a new copy, and whether BizHawk starts after every save. The editor can also back up your work every few minutes: it writes a small plan of your edits (nothing from the game) to its backup folder and keeps the newest ones. Open the backup folder shows them; to bring one back, open your ROM and use File > Import edits.

Warnings

Switch off the hints you no longer need: the triangle and collision counts in the import window, the note about objects on moving parts, the warning about very long names and the one about large animations. Problems that would stop a save from working are always shown.
