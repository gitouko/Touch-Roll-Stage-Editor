World and stage names

Edit > World and stage names… (Ctrl+Shift+N) renames the twelve worlds and their stages. Pick a world on the left and type the new names. The original name stays next to each field, and the small arrow puts it back.

Stage names are also shown in big letters when a stage starts, using a font that only has capital letters. So stage names use capitals, digits, spaces and these marks: - ? ! ' : ( # ) . + = & / , * ; @ < >. If you type in lower case, the editor turns it into capitals for you. World names can use upper and lower case and the usual punctuation, except the percent sign.

A name can be up to 24 characters long. The meter under each field turns orange once a name gets longer than the longest names in the game, because a very long name may not fit everywhere it's shown. Names apply to all five languages of the game.
