Drawing range

Every stage model can only draw things within a certain distance of its centre. In 1-1, for example, that's 16 units in each direction. Collision and objects don't have this limit, only what's drawn.

Stage > Drawing range… lets you double it or make it four times as big. The stage looks exactly the same afterwards, so there's no harm in widening it when you need the room. The editor suggests it whenever a platform you're adding is too far out to be drawn.

You can go back to a smaller range as long as nothing is drawn beyond it.
