Getting started

Opening your ROM

When the editor starts, the start page has a big Open your Touch & Roll ROM… button and a list of the ROMs you opened recently. You can also choose File > Open ROM… (Ctrl+O) at any time. The editor only accepts the USA version, and it tells you if the file is something else. ROMs you've opened before are listed under File > Open recent too.

If you open a copy that the editor saved earlier, it offers to open the original ROM instead and load that copy's edits on top. Say yes: every save then starts from the clean original, which keeps things simple and reliable.

The window

On the left is the list of stages, sorted by world. Type part of a name (or a number like 3-7) into the box above it to find a stage quickly. Below the twelve worlds you'll find the stage files the main game doesn't use, such as the party modes.

In the middle are the views. The first tab shows the stage from above with a side view underneath it; the second tab is the 3D view. On the right, the Selected tab shows whatever you've clicked on and lets you type exact values, and Stage info lists facts about the stage. The bottom of the window shows the banana total and how many changes you've made.

A first edit

Pick 1-1 in the list. Click the start (the green dot with an arrow) and drag it somewhere else, or press 1 and click on the floor to drop a banana. Press Ctrl+S to save. The first time, the editor asks where to put the new ROM; after that, Save keeps updating the same copy. If you've told the editor where BizHawk is, F5 starts the saved copy straight away.

Undo and redo

Everything you do can be undone with Ctrl+Z and redone with Ctrl+Y, including changes to names, new stages and keyframes. The Edit menu shows what the next undo will take back.
