Keyboard shortcuts

KeyWhat it does
Ctrl+OOpen a ROM
Ctrl+SSave
Ctrl+Shift+SSave as a new copy
F5Play the saved copy in BizHawk
Ctrl+Z / Ctrl+YUndo / redo
1, 2, 3, 4Add a banana, a bunch, a bumper, a goal (then click on the top view)
P, I, RAdd a platform, an invisible floor, a no-collision area (then drag a rectangle)
EscCancel adding
DelDelete the selected object, shape or key
Ctrl+DDuplicate the selected object or shape
Arrow keysNudge the selection (in the keyframe curve: move the selected key)
Page Up / Page DownRaise / lower the selection
Q / ETurn left / right 15° (with Shift: 1°; both can be changed in Settings)
CShow or hide collision
FFit the whole stage in view
Home, T3D view: behind the start, from above
Ctrl+1 / Ctrl+2Map / 3D view
Ctrl+KKeyframe editor
Ctrl+Shift+NWorld and stage names
Ctrl+,Settings
