Importing 3D models

This is the recommended way to make custom geometry. Build the shape in a 3D program such as Blender or Wings3D, export it as an .obj file, and bring it into a new stage with Geometry > Import OBJ model…. The editor turns it into something the game draws and the ball can roll on, corner for corner.

Models can be imported into new stages, the ones made with Stage > Create new stage here.

Exporting from your 3D program

In Blender, use File > Export > Wavefront (.obj) and keep "Y up" (the default). In Wings3D, use File > Export > Wavefront (.obj). Other programs work the same way; if a model comes in lying on its side, pick Z is up in the import window. One unit in your 3D program is one unit in the stage, and the ball is about one unit across, which helps when you're judging sizes.

The editor reads everything a 3D program normally writes: objects and groups, materials (and the .mtl file next to the .obj), texture coordinates, normals, faces with any number of corners, even concave ones, and vertex colours. Normals and colours are skipped, because the game lights the stage itself, and so are lines and points, which have no surface.

Each face is drawn and solid from its front, the side where its corners go round counter-clockwise. 3D programs do this for you, but if part of your model is missing in the game or the ball falls through it, flip that part's faces in your 3D program, or tick Both sides when you import.

The import window

On the left you set how the whole file comes in. Scale has a box for X, Y and Z; with Keep proportions ticked they change together, and unticked you can stretch the model along one axis. Position is where the bottom middle of the whole file goes, and Tilt / Swivel / Rotate turns it. Choose whether it's Drawn, Solid or both: a model that's drawn but not solid makes a nice decoration, and one that's solid but not drawn works as an invisible floor in any shape you like.

On the right, Objects in the file lists every object (or group) in the .obj with its size. Each one becomes its own piece in the stage, laid out just as it was in your 3D program. Untick any you don't want.

Every object on its own

After importing, each object shows up as its own model. Click one to select it, then move it, turn it, scale it along X, Y and Z, make it a decoration or an invisible floor, or delete it, without touching the others. A piece turns and scales about its own bottom middle. So you can build a whole course in one file and still fine-tune each part in the editor.

Materials and textures

For now the game's own textures stand in for yours. Under Textures the import window lists the materials of your file, and next to each one you pick which of the stage's textures it's drawn with. Each model piece shows the same list on the right, so you can change your mind later. Tick Use the file's texture coordinates to lay each texture on the way your UV map does; untick it to lay textures on from above, like on platforms.

Bringing in your own pictures as textures is planned for version 1.1. Until then, pick the stage texture that comes closest to what you had in mind; the UV map you made still decides where it sits.

Keep it light

The DS is a small machine. The most detailed stage in the game draws about 3,300 triangles, and the import window warns you if your stage would go past that. A single import can have up to 3,000 triangles. Simple, chunky shapes look right at home in this game, so there's rarely a need for more.
