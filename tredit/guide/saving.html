Saving and sharing

Saving

File > Save (Ctrl+S) writes your changes to a new ROM. The first time it asks for a file name; after that it keeps updating the same copy. Save as new copy… (Ctrl+Shift+S) starts a fresh one. Everything goes into that one save: objects, platforms, models, new stages, keyframes, names and drawing ranges, all checked and verified together.

Next to the ROM you'll find a .patch.json file. It's a readable record of every change, and the editor uses it to pick up where you left off when you open that copy again.

Playing

File > Play saved copy in BizHawk (F5) starts the saved ROM in BizHawk. The first time, tell the editor where EmuHawk.exe is with Set BizHawk (EmuHawk.exe) location….

Sharing your work

The game itself can't be passed around, but your edits can. File > Export edits as plan (.json)… writes a small file with your changes and nothing from the game. Anyone with their own copy of the game opens their ROM, chooses File > Import edits…, picks your file, and gets exactly your stages. Importing works with a saved copy's .patch.json, too.
